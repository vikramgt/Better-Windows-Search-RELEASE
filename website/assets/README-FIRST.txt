RECALL ? FIRST RUN (WINDOWS 10/11, 64-BIT)

1. Run FileScout-Setup and install FileScout for your Windows account.
2. Open FileScout from the Start menu at least once. On first launch, choose whether
   to allow automatic local search or select folders manually. Cancel grants no
   search access. Your files and extracted text are processed locally.
3. Keep FileScout open for the first indexing pass. Image understanding can take
   longer than filename/date/size indexing; cached results are reused later.
4. With File Explorer active, press Ctrl+Shift+F to open the FileScout search bar.
   The installer enables this shortcut and Search with FileScout in the right-click
   menu when its Explorer integration option is selected. Your normal Ctrl+F
   continues to use Windows search. If you have not configured search access,
   FileScout opens its first-run window before allowing Explorer indexing.
5. Try: people holding trophies; photos downloaded last week;
   PDFs downloaded last month under 5 MB.

This package includes Python, app dependencies and the local image model.
No Python installation, pip commands, model download, account or network
connection is required to use this build. If a suitable Microsoft Visual C++
runtime is missing, Setup installs the bundled prerequisite and Windows may
request administrator approval for that Microsoft component. Image matches are approximate. Dates
use file creation time as a download-time proxy.

Files are not copied, moved or uploaded by FileScout. The search index and extracted
text are stored unencrypted under %LOCALAPPDATA%\FileScout. Windows file
permissions remain in effect. You can change access in Settings > Search access.

Uninstall using Windows Settings > Apps > Installed apps > FileScout. App files and
this copy's integrations are removed. Your original files and local search data
are retained. Removing the local index manually is optional and not secure erasure.

This is an unsigned prototype build. Windows may display a publisher/reputation
prompt. Only run installers obtained from the project's trusted release source.

FREE AND PRO
All features are available for up to 500 indexed files. FileScout Pro unlocks
unlimited indexed files for EUR 20 one-time. Activation requires an internet
connection; the activated license is saved locally for offline use.
Pro sales and the coffee link are not configured in this preview build.
Native OCR uses installed Windows recognition languages and skips unsupported files.
