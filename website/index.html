First run

Install, then open FileScout once.

Choose search access before using the Explorer shortcut.

  1. Install the app

    Extract the ZIP and run the setup. Keep Explorer integration selected to enable the shortcut.

  2. Choose file access

    Open FileScout and allow automatic search, or choose folders manually. Keep it open for the first indexing pass.

  3. Open File Explorer

    Press Ctrl + Shift + F and enter your search. Your usual Ctrl + F is unchanged.
